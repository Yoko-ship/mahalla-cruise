# Painted Garage Cars

Generated 2026-10-22 with the built-in image generation tool. These are 2D sprites,
not editable 3D meshes. The Damas in `../vehicles_aligned.png` supplies style and
camera; the existing Blender renders supply vehicle identity. Originals are kept
here; `.gdignore` excludes these high-resolution sources from runtime import.

The references derive from the CC-BY models listed in
[model credits](../../../art_sources/car_models/CREDITS.md). Retain those author
attributions for these adaptations too. Source provenance review noted in the
existing car README remains open.

Pack with `./scripts/godot.sh --headless --path . --script scripts/render_roster_cars.gd -- --painted`.
The packed atlas is `../roster_painted.png`; the older Blender atlas is preserved.
